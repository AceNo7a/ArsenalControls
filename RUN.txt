Arsenal Controls 1.0.0-beta.3 - main loader

Run this line in your executor while in a Roblox game:

loadstring(game:HttpGet("https://raw.githubusercontent.com/AceNo7a/ArsenalControls/main/mainloader.lua"))()

mainloader.lua and loader.lua now resolve GitHub's main reference and fetch
the script at that exact commit. The standalone main/dist/ArsenalControls.lua
URL remains available, but GitHub can temporarily cache older branch content.

All active features start off. Right Shift shows/hides the UI; F8 stops all.
Outside Arsenal, auto fire uses an equipped standard Tool. Autoplay can equip
the first backpack Tool. Select Pulse/Hold to suit the Tool and adjust autoplay
stop distance for melee or ranged use. Custom weapon systems may need adapters.

README.txt covers usage; VALIDATION.txt records checks and limitations.

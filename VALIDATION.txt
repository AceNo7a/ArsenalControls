LIVE LIMITATIONS
A local Roblox Tool activation fixture was attempted through Madium but
skipped because the character was not alive. No full cross-game combat match
has been completed for this release. The behavior fixtures use mock objects;
they verify the adapter/controller logic, not an arbitrary game's server.
Support applies to standard Humanoids and weapons using Tool activation.
Cursor-based targeting, custom weapon input, reload/ammo, custom teams, NPC
targets and server damage acceptance are game-specific and unverified.
Arsenal keeps its existing adapter. Silent aim, recoil and client ammo remain
Arsenal-specific; previous beta limitations still apply.

MAIN LOADER
Both loader.lua and mainloader.lua resolve main with GitHub's public refs
API, then fetch dist/ArsenalControls.lua by commit SHA. They do not silently
fall back to an older version when resolution fails. The public API may be
rate-limited. Existing raw branch URLs can be temporarily cached by GitHub.
